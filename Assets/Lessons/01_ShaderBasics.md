# Этап 1.1: Введение в шейдеры Unity

## Что такое шейдер?

**Шейдер** — это программа, которая выполняется на GPU (графическом процессоре) и определяет, как объекты отображаются на экране. В отличие от обычного кода на C#, который выполняется на CPU последовательно, шейдеры выполняются **параллельно** для тысяч пикселей/вершин одновременно.

## Почему шейдеры важны для PowderGame?

В классической реализации PowderGame каждая частица обрабатывается на CPU, что ограничивает количество частиц (обычно ~100,000). Используя GPU и шейдеры, мы можем:
- Симулировать **миллионы частиц** параллельно
- Реализовать **field-based** симуляцию газов эффективно
- Получить высокую производительность рендеринга

## Типы шейдеров в Unity

### 1. Surface Shaders (Высокоуровневые)
- Упрощённый синтаксис Unity
- Автоматически обрабатывают освещение
- Хороши для стандартных материалов
- **НЕ подходят** для нашей симуляции

### 2. Vertex/Fragment Shaders (Низкоуровневые)
- Полный контроль над рендерингом
- Два этапа: обработка вершин → обработка пикселей
- **Используем** для отображения симуляции

### 3. Compute Shaders (Вычислительные)
- Выполняют произвольные вычисления на GPU
- Не связаны напрямую с рендерингом
- **ОСНОВНОЙ ИНСТРУМЕНТ** для нашей симуляции частиц и газов

## Графический конвейер (упрощённо)

```
[Вершины меша]
      ↓
[VERTEX SHADER] ← Преобразование позиций вершин
      ↓
[Растеризация] ← GPU разбивает треугольники на пиксели
      ↓
[FRAGMENT SHADER] ← Определение цвета каждого пикселя
      ↓
[Экран]
```

## Основы языка HLSL

Unity использует **HLSL** (High-Level Shading Language) для написания шейдеров.

### Базовые типы данных

```hlsl
// Скалярные типы
float x = 1.0;      // 32-бит число с плавающей точкой
half y = 0.5;       // 16-бит (менее точный, но быстрее)
int i = 5;          // Целое число
bool b = true;      // Логический тип

// Векторные типы (ОЧЕНЬ ВАЖНО!)
float2 uv = float2(0.5, 0.5);           // 2D вектор (u, v координаты)
float3 color = float3(1.0, 0.0, 0.0);   // RGB цвет (красный)
float4 rgba = float4(1.0, 0.0, 0.0, 1.0); // RGBA (с альфа-каналом)

// Доступ к компонентам
float r = rgba.r;   // или rgba.x - первый компонент
float g = rgba.g;   // или rgba.y
float b = rgba.b;   // или rgba.z
float a = rgba.a;   // или rgba.w

// Swizzling - перестановка компонентов
float3 bgr = rgba.bgr;  // Меняем порядок
float2 xy = rgba.xy;    // Берём только первые два
```

### Текстуры и сэмплирование

```hlsl
// Объявление текстуры
Texture2D<float4> _MainTex;  // 2D текстура с 4 каналами
SamplerState sampler_MainTex; // Сэмплер (как читать текстуру)

// Чтение из текстуры
float4 color = _MainTex.Sample(sampler_MainTex, uv);
// uv - координаты от 0 до 1
```

### Математические функции

```hlsl
// Часто используемые функции
float a = lerp(0.0, 1.0, 0.5);  // Линейная интерполяция = 0.5
float b = saturate(1.5);         // Ограничение в [0,1] = 1.0
float c = step(0.5, 0.7);        // 0.7 >= 0.5 ? 1 : 0 = 1
float d = smoothstep(0.0, 1.0, 0.5); // Плавная интерполяция

float e = abs(-5.0);    // Модуль = 5.0
float f = floor(2.7);   // Округление вниз = 2.0
float g = frac(2.7);    // Дробная часть = 0.7
float h = clamp(x, 0.0, 1.0); // Ограничение в диапазоне
```

## Структура шейдера в Unity

```hlsl
Shader "Custom/MyShader"    // Имя в меню выбора шейдера
{
    Properties              // Параметры, видимые в Inspector
    {
        _MainTex ("Texture", 2D) = "white" {}
        _Color ("Color", Color) = (1,1,1,1)
    }
    
    SubShader               // Вариант рендеринга
    {
        Tags { "RenderType"="Opaque" }
        
        Pass                // Один проход рендеринга
        {
            HLSLPROGRAM     // Начало HLSL кода
            #pragma vertex vert
            #pragma fragment frag
            
            // ... код шейдера ...
            
            ENDHLSL
        }
    }
}
```

## Практическое задание

Для закрепления теории, создайте в Unity:

1. **Откройте Unity проект** "powder game"
2. **Создайте папку** `Assets/Shaders`
3. **Создайте новый Unlit Shader:**
   - ПКМ в папке Shaders → Create → Shader → Unlit Shader
   - Назовите его `TestShader`
4. **Откройте созданный файл** и изучите его структуру

После создания шейдера сообщите мне, и мы перейдём к следующему шагу, где модифицируем его.

## Ключевые концепции для запоминания

| Концепция | Описание |
|-----------|----------|
| **Параллелизм** | Шейдер выполняется для всех пикселей одновременно |
| **Vertex Shader** | Обрабатывает позиции вершин |
| **Fragment Shader** | Определяет цвет каждого пикселя |
| **Compute Shader** | Произвольные вычисления на GPU |
| **float4** | Вектор из 4 чисел (RGBA, XYZW) |
| **UV координаты** | Позиция на текстуре от (0,0) до (1,1) |
| **Сэмплирование** | Чтение значения из текстуры |
